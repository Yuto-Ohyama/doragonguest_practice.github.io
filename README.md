Pythonでドラゴンクエストを1から作る

boukennnosy1.json　にデータが入力される

doraque.py　がメインのファイル(追加でアップデートしていきます)

doraque_GUI.py doraque_gui_command.py　はGUIの練習で作ったもの(未完成)

input_int.py　は必要なモジュール


<プレイするには>
acacondaのコンソールに出力されるのがメインのゲームです。

pythonファイルを自分のフォルダにコピーする。(※Python,anacondaの環境設定が必要)
anacondaを開き、pythonファイルが入っているフォルダのパスをanacondaへ入力。
"python doraque.py"　とコンソールに入力する。
出力されるコマンドに沿ってプレイしてください。

データを消したい場合、boukennnosyo1.jsonファイルを直接編集して好みのステータスにすることができます。
